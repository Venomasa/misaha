## نبذة عن المشروع
تطبيق كاداسترالي خفيف وسريع مخصص للمساحين والمهندسين الزراعيين والملاك، يعمل بالكامل بدون اتصال بالإنترنت (Zero Data). يتيح تخطيط وحساب كروكيات الأراضي، تعديل الأركان والزوايا والأوتار، وحساب المساحات بالنظامين المتري والزراعي (فدان / قيراط / سهم)، مع تصدير مخططات هندسية بصيغتي PDF و PNG.

## المميزات الأساسية
- **كروكي الأراضي التفاعلي:** رسم وتعديل أطوال الأضلاع والزوايا والأوتار الداخلية بدقة مع تحديث لحظي للمساحة والمحيط.
- **حاسبة الأشكال الهندسية (12 شكلاً):** حساب دقيق للأشكال القياسية وغير المنتظمة (رباعي بالأوتار، شبه منحرف، مثلثات، أشكال L و T، خماسي).
- **محول الوحدات الزراعية:** تحويل فوري ودقيق بين الفدان والقيراط والسهم والمتر المربع والقصبة مع توضيح العلاقة التجميعية.
- **تصدير المخططات المعمارية:** تصدير مباشر إلى PDF و PNG بدقة عالية ومقياس رسم بياني معتمد بدون الحاجة لإنترنت أو طابعات خارجية.
- **واجهة ثنائية اللغة:** دعم كامل ومكتمل للغتين العربية والإنجليزية مع ضبط تلقائي للاتجاه (RTL / LTR).
- **أداء فائق ومرن:** كود فائق الخفة (177 KB) بدون أي بطء أو استهلاك زائد للذاكرة متوافق مع كافة هواتف أندرويد.

## التثبيت والتشغيل
1. قم بتحميل ملف `misaha.apk` مباشرة عبر زر التحميل الأخضر أعلاه.
2. افتح الملف على هاتف الأندرويد وقم بتثبيته.
3. يعمل التطبيق بدون إنترنت نهائياً وبدون أي أذونات غير ضرورية.
